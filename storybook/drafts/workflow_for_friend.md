# 用自己的电脑给孩子做绘本：流程说明

## 一句话
在自己的电脑上跑图像模型（ComfyUI），让 AI 助手（Claude Code）写故事、写画面描述、出图、逐页检查、改错重画，最后做成网页和能直接拿去印的文件。孩子的照片不出自己的电脑。

## 需要什么
- **一台有 N 卡的电脑。** 我用的是 8GB 显存的笔记本、32GB 内存，够用。显存再小就很吃力。
- **ComfyUI**，加上 **ComfyUI-GGUF** 插件（用来跑压缩过的大模型）。
- **模型：**
  - **Qwen-Image-2512**（GGUF Q3 压缩版）加 **Lightning 8 步 LoRA**：文字生成图片，一页大约 75 秒。
  - **Qwen-Image-Edit-2511**（Q3_K_M）：只在要画自己孩子的时候用，给它两张孩子的照片当参考，一页大约 3 分钟。不画孩子的书用不到。
- **Claude Code**：它来写脚本、调模型、看图、改错。

## 流程
1. **定题目和写法。** 比如"学 *Dragons Love Tacos* 的讲法：对'你'说话，一本正经讲荒唐事，前面警告一件小事，后面这件事一定发生"。只学手法，故事和句子自己写。
2. **写脚本。** 每本 32 页。每页两样东西：
   - 中文旁白，一两句，给大人念；
   - 英文画面描述，给模型看。
3. **定画风。** 画风那句话只写媒介和纸，比如"斑点米色纸，平涂色块，细的歪歪扭扭的线"。
4. **出图。** 32 页大约 40 分钟。
5. **逐页检查。** 对着旁白看，画错的改描述重画。一本通常要重画五到十页。
6. **做成网页。** 图和文字一页一页翻，发链接给家人。
7. **做印刷文件。** 图放大到 3071×3071（10 寸，加 3 毫米出血，300dpi），字自动放在画面最空的角上，合成 PDF，也导出一页一张的 JPG。

## 印书
- **在淘宝搜"照片书 定制 精装"**，一本起印。
- **选 10 寸方款**，跟正方形的图正好配。
- **纸：** 哑光铜版或哑粉纸，200 克左右。
- **装订：** 孩子小的话选"对裱"厚页，翻不坏。
- **覆膜：** 选哑膜。
- **先印一本试颜色**，印出来常常比屏幕暗一点。

## 最值钱的几条经验
- **提示里写到的每个名词，模型都会画出来。**
  - 把角色写进画风，每一页都会挤满角色。
  - 写"不要贴纸"，反而会出贴纸边。
  - 写"砖红色"，画面空的地方会出现一块砖。
  - 所以画风只写纸和线条，角色写进每一页的描述，并写清楚几只。
- **画面太空，模型会自己塞东西。** 空的页给一个具体的地方，比如"一只袜子躺在木地板上""一大片空草地"。
- **同一句描述、同一个随机数重画，结果几乎一样。** 要改就改描述，或者给这一页换一个随机数。
- **画孩子别写"只画头和肩"。** 模型会把头画大，大头、鼓眼，很吓人。写"正常五岁孩子的比例"。
- **每页都要过两关：** 一眼看得懂，对孩子友好。不要尖牙，不要凶脸，也不要吓人的特写。
- **模型爱给画加黑边框**，出完用程序裁掉，比重画省事。

## 可以直接复制给 Claude Code 的提示

> 我想在自己的 Windows 电脑上用 ComfyUI 给我 4 岁的孩子做绘本，每本 32 页。请帮我：
>
> 1. **检查环境并装好：** ComfyUI、ComfyUI-GGUF，模型用 Qwen-Image-2512 的 GGUF Q3 版加 Lightning 8 步 LoRA。我的显卡显存是 ___GB。
> 2. **写一个出图脚本：** 读一个 JSON 故事文件（每页有中文旁白 zh 和英文画面描述 scene），逐页调 ComfyUI 出图，出过的页跳过，中断了能接着跑，每张图失败自动重试。
> 3. **先跟我定故事：** 题目是 ___，风格学 ___（只学讲法，故事和句子要原创）。先给我大纲，我同意了再写 32 页脚本。
> 4. **写画面描述时遵守这些规则：**
>    - 画风那句只写媒介和纸，不写角色、不写否定句、不写能被画成东西的颜色名（比如砖红）；
>    - 角色描述写在每一页里，写清楚画几只；该没有角色的页写"no X in the picture"；
>    - 画面里不要任何文字；
>    - 很空的页给一个具体的场景。
> 5. **每出完一本，一页一页对着旁白检查：** 画错的、看不懂的、对孩子不友好的（尖牙、凶脸、吓人的特写），改描述重画，带黑框的裁掉。
> 6. **全部合格后：**
>    - 做成可以一页页翻的网页；
>    - 再做印刷文件：图放大到 3071×3071 像素（10 寸加 3 毫米出血，300dpi），旁白用清楚的中文字体、28pt 左右，自动放在画面最空的位置，字后面必要时垫一块半透明的纸色底；输出 PDF 和一页一张的 JPG；
>    - 最后看一遍全书缩略图，画风不一致的页重画。
>
> 做每一步之前先告诉我你打算怎么做，出图前先试两三页给我看画风。
